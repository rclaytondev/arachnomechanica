This is a procedurally generated 2D platformer game about creatures with complex emergent behavior. The following is the main content of the game:
- Lizards that breathe fire when obstructed
- Spiders that crawl along the perimeter walls and shoot fireballs, but become scared afterwards
- Robots that teleport underneath the player and then shoot fire upwards
- Laser beams that quickly spin around and deal damage upon collision
- Electricity orbs that bounce off of walls
- Gates that toggle every time the player goes through
- Solid blocks that can be picked up and thrown to manipulate enemies
