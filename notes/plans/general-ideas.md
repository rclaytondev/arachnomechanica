
I'm going to rethink the plan for the whole game.

Core components:
- **Procedural generation**: I've already made some mechanics (lizards, lasers, and gates) that work really well with procedural generation due to their simple rules that produce complex interactions, so I might as well keep doing procedural generation since it's just infinite free content.
- **A multi-layered world / quest**: I want to evoke the feeling of a rabbit hole that keeps getting deeper. For example, I think Noita does this pretty well: you can leave the main path and there's a whole secret world to explore; in fact, the secret content is larger than the main path itself!
- **Knowledge-based progression**: Some, but not all, of the progression should be knowledge-based, because knowledge-based progression is really cool. For example, it's great to revisit an earlier area and realize that there was something that was in front of you all along but that you didn't realize (e.g. the Holy Cross, or the Quantum Moon)

Optional ideas:
- **Roguelike?**:
	- `+` Re-randomizing the layout on each death works well with procedural generation
	- `+` It also makes it so that the player doesn't get bored re-traversing areas they've already cleared.
	- `+` It does work well with some quest step ideas I have, for example entering the code obtained from the runes.
	- `+` It makes the game seem bigger than it actually is (but is this actually a good thing?)
	- `-` It doesn't work well with some quest step ideas I have, for example using lizards to break the walls of the tower and get to the sky islands.
	- `-` If I don't make it a roguelike, the re-traversing issue can still be fixed by using portals like in Dead Cells.
- **Random progression items?**:
	- `+` It's always satisfying to feel like you're rewarded for your exploration. (Not necessary though -- see Celeste)
	- `+` This can add variation to the runs and help distinguish good runs from bad runs.
	- `-` Without a combat system, I don't actually have many good ideas for what to add. (Perhaps look to Rain World for guidance?)
	- `-` This can make it feel luck based; it sucks to just not get any good items for a while. (Perhaps this can be fixed by making every item strong, like in Dead Cells and unlike in Spelunky).
- **Non-random progression items?** (note that this is still compatible with random progression items):
	- `+` This is better if I don't have many item ideas: you can unlock each one after reaching a certain point, like in Hollow Knight.
	- `+` This allows for good control over progression.
